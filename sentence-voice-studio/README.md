# Sentence Voice Studio

โปรแกรม Windows สำหรับแปลงข้อความเป็นเสียง MP3 พร้อมระบบ **Voice Director** สำหรับกำกับอารมณ์ จังหวะ และปฏิกิริยาระหว่างพูด

## Version 0.3.1 — Edge TTS Stability Fix

แก้ปัญหา `No audio was received` ที่อาจเกิดเป็นครั้งคราวจากบริการ Edge TTS แม้ข้อความและเสียงถูกต้อง

- Retry อัตโนมัติสูงสุด 3 ครั้ง
- สองครั้งแรกคงอารมณ์/Prosody เดิม
- ครั้งสุดท้ายลองเสียงเดิมด้วย Prosody กลาง เพื่อกันพารามิเตอร์อารมณ์เฉพาะช่วงทำให้ request ล้ม
- ตรวจว่าไฟล์เสียงที่ได้มีข้อมูลจริงก่อนถือว่าสำเร็จ
- ถ้ายังล้มเหลว จะแสดงข้อความภาษาไทยที่อธิบายว่าเป็นปัญหา Edge TTS/เครือข่ายและแนะนำทางเลือก

### 2. เลือกอารมณ์ได้จาก UI

ไม่ต้องจำแท็กเอง:

- Dropdown เลือกอารมณ์
- ปุ่ม “แทรก [อารมณ์] ที่เคอร์เซอร์”
- ปุ่มลัด [อุทาน], [สงสัย], [ครุ่นคิด], [หัวเราะ], [ถอนหายใจ], [กระซิบ], [จริงจัง]

### 3. วิเคราะห์อารมณ์อัตโนมัติ

ปุ่ม **วิเคราะห์อารมณ์อัตโนมัติ** จะดู punctuation และคำสำคัญในแต่ละประโยค แล้วใส่แท็กที่คาดว่าเหมาะสมลงในข้อความให้เห็นก่อนสร้างเสียง

ตัวอย่าง:

    จริงเหรอ? โห! ทำได้ขนาดนี้เลย

อาจกลายเป็น:

    [สงสัย] จริงเหรอ? [อุทาน] โห! ทำได้ขนาดนี้เลย

ผลการวิเคราะห์เป็นเพียงคำแนะนำและแก้เองได้เสมอ โปรแกรมจะไม่วิเคราะห์ทับบรรทัดที่มีแท็กจากผู้ใช้อยู่แล้ว

### 4. ใส่คำกำกับแบบภาษาธรรมชาติได้

ไม่จำเป็นต้องใช้ชื่อแท็กเป๊ะ เช่น:

    [พูดช้าและจริงจัง]
    [ถามแบบสงสัย]
    [พูดเบาเหมือนกระซิบ]

โปรแกรมจะพยายามจับคู่กับอารมณ์ที่รองรับ และข้อความในวงเล็บเหลี่ยมจะไม่ถูกอ่านออกเสียง

### 5. Engine

#### Edge Neural — ฟรี

- ไม่ต้องใช้ API Key
- รองรับ Premwadee, Niwat, Achara และเสียงออนไลน์อื่น
- Voice Director จะจำลองอารมณ์แต่ละช่วงด้วย Rate / Pitch / Volume
- เหมาะกับงานทั่วไปและการทดลอง

ข้อจำกัด: หัวเราะ ถอนหายใจ กระซิบ และอารมณ์ซับซ้อนไม่ใช่ reaction model จริง

#### Azure Thai MAI

รองรับเสียงไทย:

- th-TH-Krit:MAI-Voice-2
- th-TH-Nattapong:MAI-Voice-2
- Flash variants

Voice Director แปลงแท็กเป็น style เช่น excited, curious, reflective, serious, friendlycheerful, caringempathy และ saddisappointed

ต้องมี Azure Speech Key และ Region โดย Key ที่กรอกในโปรแกรมจะไม่ถูกบันทึกลงไฟล์

#### ElevenLabs v4

เหมาะที่สุดเมื่ออยากได้ voice acting และ human reactions เช่น:

- [laughs]
- [sighs]
- [whispers]
- [clears throat]
- [curious]
- [excited]

โปรแกรมแปลงแท็กภาษาไทยของ Voice Director เป็น audio tags ที่เหมาะสมให้

ต้องใช้ ElevenLabs API Key และ Voice ID โดย Key ที่กรอกในโปรแกรมจะไม่ถูกบันทึกลงไฟล์

### 6. จังหวะพูด

    |   = พักสั้น
    ||  = พักยาว

ใช้ร่วมกับแท็กได้ เช่น:

    [ครุ่นคิด] บางที... | เราอาจไม่ต้องพูดเร็วขนาดนั้น ||
    [อุทาน] จริงไหม!

## ใช้งานกับ AI เขียนสคริปต์ตัวอื่น

ให้ AI ตัวเขียนสคริปต์ส่งออก **ข้อความพูดจริง + Voice Director tags ในวงเล็บเหลี่ยม** เท่านั้น

ตัวอย่างรูปแบบมาตรฐาน:

    [เป็นกันเอง] หลายคนใช้ AI ทุกวัน ||
    [ครุ่นคิด] แต่เคยสงสัยไหมว่า... เราใช้มันถูกจุดหรือยัง?
    [อุทาน] เพราะบางงาน AI ลดเวลาได้เป็นชั่วโมง!
    [จริงจัง] แต่ข้อมูลสำคัญ ต้องตรวจสอบก่อนใช้เสมอ
    [อบอุ่น] ถ้าคลิปนี้ช่วยได้ ฝากติดตามไว้ด้วยนะครับ

ห้ามใส่ Stage Direction นอก [] เพราะข้อความนอก [] จะถือว่าเป็นคำพูดที่ต้องอ่านออกเสียง

    pyinstaller --noconfirm --clean --onefile --windowed --name SentenceVoiceStudio --collect-all edge_tts sentence_voice_studio.py
